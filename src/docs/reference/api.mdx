플래닛어스는 서버 내 데이터에 접근할 수 있는 공개 REST API를 제공합니다.  
국가 디스코드 봇 제작, 외부 사이트 연동, 자동화 등 다양한 용도로 활용할 수 있습니다.

## 기본 정보

| 항목 | 내용 |
|------|------|
| Base URL | `https://api.planetearth.kr` |
| 응답 형식 | JSON |
| 인증 | 없음 (공개 API) |
| 단건 조회 캐시 | 5분 (결과가 없으면 1분) |
| 목록·Bulk 데이터 | 5분마다 갱신 (평소 최대 약 7분 지연, 갱신 장애 시 최대 1일 전 데이터) |
| 온라인 정보 | 최대 5분 지연 |

- 모든 응답에 `ETag` 헤더가 붙습니다. 다음 요청에 `If-None-Match` 헤더로 보내면 데이터가 바뀌지 않았을 때 본문 없이 `304`를 받습니다.
- 마을·국가 이름에 특수문자(`Edo[江戸]`, `Washington_D.C.` 등)가 있으면 URL 인코딩해서 보내주세요.

## User-Agent 규칙

**2026년 11월 15일부터** 모든 요청의 `User-Agent` 헤더에 마인크래프트 닉네임을 `Minecraft:<닉네임>` 형식으로 넣어야 합니다. 문제가 생겼을 때 개발자에게 연락하기 위해서입니다.

```
User-Agent: MyBot/1.0 (Minecraft:Steve)
```

- 봇 이름과 버전은 자유롭게 정해도 됩니다. 대소문자는 구분하지 않고, `:` 뒤에 공백이 있어도 됩니다.
- 닉네임이 없으면 `403`과 `USER_AGENT_REQUIRED` 에러를 받습니다.
- 브라우저로 주소를 직접 열 때와 `/health`는 예외입니다.

---

## 요청 제한

| 종류 | 제한 |
|------|------|
| 일반 엔드포인트 | IP당 **1분에 약 30회** |
| Bulk 엔드포인트 | IP당 **엔드포인트별로 1분에 약 2회** |
| `/health` | IP당 **1분에 약 60회** |

제한을 넘으면 `429`와 `Retry-After` 헤더(초 단위)를 받습니다. 그 시간만큼 기다린 뒤 다시 요청해주세요.

:::tip
여러 마을·국가·주민 정보를 한꺼번에 가져와야 한다면 단건 조회를 반복하지 말고 Bulk 엔드포인트를 사용해주세요.
:::

## 응답 형식

모든 응답은 `status` 필드를 포함합니다.

**성공**
```json
{
  "status": "SUCCESS",
  "data": [ ... ]
}
```

**실패**
```json
{
  "status": "FAILED",
  "error": {
    "code": "NO_DATA_FOUND",
    "message": "주어진 입력에 맞는 정보를 찾을 수 없습니다."
  }
}
```

### 에러 코드

| 코드 | HTTP | 설명 |
|------|------|------|
| `NO_DATA_FOUND` | 404 | 조건에 맞는 데이터 없음 |
| `NOT_FOUND` | 404 | 존재하지 않는 엔드포인트 |
| `NO_PARAMETER_PROVIDED` | 400 | 파라미터 누락 |
| `MULTIPLE_PARAMETERS_PROVIDED` | 400 | 파라미터 2개 이상 입력 |
| `INVALID_PARAMETERS_PROVIDED` | 400 | 파라미터 형식 오류 |
| `INVALID_NAME_PROVIDED` | 404 | 플래닛어스에 접속한 적 없는 닉네임 (`/discord?name=`) |
| `RATE_LIMITED` | 429 | 요청 횟수 초과 |
| `USER_AGENT_REQUIRED` | 403 | `User-Agent`에 마인크래프트 닉네임 없음 ([User-Agent 규칙](#user-agent-규칙)) |
| `UPSTREAM_ERROR` | 502 | 지도 서버 연결 실패 (`/online`) |
| `SERVER_ERROR` | 500 | 서버 내부 오류 |

## 엔드포인트

### 마을

#### `GET /town`

이름 또는 UUID로 마을 정보를 조회합니다.

**Query Parameters**

| 파라미터 | 타입 | 설명 |
|----------|------|------|
| `name` | string | 마을 이름 |
| `uuid` | string | 마을 UUID |

> 파라미터는 하나만 입력해야 합니다.

**Response Fields**

| 필드 | 타입 | 설명 |
|------|------|------|
| `name` | string | 마을 이름 |
| `uuid` | string | 마을 UUID |
| `mayor` | string | 시장 닉네임 |
| `nation` | string | 소속 국가 이름 |
| `residents` | string | 마을원 목록 (`, ` 구분, 이름순) |
| `memberCount` | number | 전체 마을원 수 |
| `onlineMemberCount` | number | 현재 온라인 마을원 수 |
| `onlineMembers` | string | 현재 온라인 마을원 목록 (`, ` 구분) |
| `claimSize` | number | 클레임한 청크 수 |
| `balance` | number | 마을 잔고 |
| `townBoard` | string | 마을 게시판 내용 |
| `trustedResidents` | string | 트러스트 주민 목록 |
| `outlaws` | string | 아웃로 목록 |
| `founder` | string | 마을 설립자 |
| `registered` | number | 마을 설립일 (Unix ms) |
| `joinedNationAt` | number | 국가 가입일 (Unix ms) |
| `spawn` | string | 마을 스폰 좌표 |

> 지도 서버에 연결할 수 없으면 `onlineMemberCount`는 `0`, `onlineMembers`는 빈 문자열입니다.

**Example Request**
```
GET https://api.planetearth.kr/town?name=Dev_Island
```

**Example Response**
```json

  "data": [
    {

      "townBoard": "d",
      "trustedResidents": "",
      "outlaws": "",
      "registered": 1663982084499,
      "spawn": "world, -1682.9804406008402, 130.0, 5095.724900104271, 37.90424, 5.7425537",
      "founder": "Irochi_",
      "joinedNationAt": 1725978155425,
      "claimSize": 87,
      "uuid": "36315f61-0685-4668-865c-87e0ca85cfda",
      "balance": 2765151.8963009114,
      "onlineMemberCount": 1,
      "onlineMembers": "Heiz"
    }
  ]
}
```

### 주민

#### `GET /resident`

닉네임, UUID, 또는 마을 이름으로 주민 정보를 조회합니다.  
마을 이름으로 조회 시 해당 마을의 마을원 전체가 반환됩니다.

**Query Parameters**

| 파라미터 | 타입 | 설명 |
|----------|------|------|
| `name` | string | 마인크래프트 닉네임 |
| `uuid` | string | 마인크래프트 UUID |
| `town` | string | 마을 이름 |

> 파라미터는 하나만 입력해야 합니다.

**Response Fields**

| 필드 | 타입 | 설명 |
|------|------|------|
| `name` | string | 닉네임 |
| `uuid` | string | UUID |
| `town` | string | 소속 마을 |
| `nation` | string | 소속 국가 |
| `townRanks` | string | 마을 직위 |
| `nationRanks` | string | 국가 직위 |
| `title` | string | 칭호 (이름 앞) |
| `surname` | string | 칭호 (이름 뒤) |
| `balance` | number | 잔고 |
| `friends` | string | 친구 목록 |
| `registered` | number | 첫 접속일 (Unix ms) |
| `lastOnline` | number | 마지막 접속일 (Unix ms) |
| `joinedTownAt` | number | 마을 가입일 (Unix ms) |
| `online` | boolean | 현재 온라인 여부 (지도 서버에 연결할 수 없으면 `false`) |

**Example Request**

```json
      "title": "",

      "friends": "",

      "online": false
    }
```

### 디스코드

#### `GET /discord`

디스코드 ID, UUID, 또는 닉네임으로 마인크래프트 ↔ 디스코드 연동 정보를 조회합니다.  
`name`으로 조회하면 플래닛어스 주민 데이터에서 UUID를 찾습니다. 서버에 접속한 적 없는 닉네임은 `INVALID_NAME_PROVIDED`(404)를 반환합니다.

**Query Parameters**

| 파라미터 | 타입 | 설명 |
|----------|------|------|
| `discord` | string | 디스코드 ID |
| `uuid` | string | 마인크래프트 UUID |
| `name` | string | 마인크래프트 닉네임 |

> 파라미터는 하나만 입력해야 합니다.

**Response Fields**

| 필드 | 타입 | 설명 |
|------|------|------|
| `discord` | string | 디스코드 ID |
| `uuid` | string | 마인크래프트 UUID |
| `name` | string \| null | 마인크래프트 닉네임 (주민 데이터가 없으면 `null`) |

**Example Request**
```
GET https://api.planetearth.kr/discord?name=Irochi_
```

**Example Response**
```json
{
  "status": "SUCCESS",
  "data": [
    {
      "discord": "1086117494189723658",
      "uuid": "626dfe3b-7820-48c7-9974-1e332b4ffe60",
      "name": "Irochi_"
    }
  ]
}
```

### 거래소

#### `GET /auction`

닉네임, UUID, 또는 경매 ID로 현재 등록된 유저 거래소 아이템을 조회합니다.  
만료된 아이템은 포함되지 않습니다.

**Query Parameters**

| 파라미터 | 타입 | 설명 |
|----------|------|------|
| `name` | string | 판매자 닉네임 |
| `uuid` | string | 판매자 UUID |
| `id` | string | 아이템 UUID |

> 파라미터는 하나만 입력해야 합니다.

**Response Fields**

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string | 아이템 UUID |
| `seller` | string | 판매자 UUID |
| `sellerName` | string | 판매자 닉네임 |
| `price` | number | 판매가 |
| `expire_at` | number | 경매 만료 일시 (Unix ms) |
| `itemInfo.type` | string | 아이템 종류 (예: `minecraft:diamond_sword`) |
| `itemInfo.amount` | number | 수량 |
| `itemInfo.displayName` | string \| null | 이름 (없을 경우 `null`) |
| `itemInfo.lore` | string[] | 설명 줄 목록 |
| `itemInfo.enchants` | object[] | 인챈트 목록 (`{ id, level }`, 인챈트 책은 저장된 인챈트) |

> 아이템 정보를 읽을 수 없으면 `itemInfo`는 `null`입니다.

**Example Request**
```
GET https://api.planetearth.kr/auction?name=Steve
```

**Example Response**
```json
{
  "status": "SUCCESS",
  "data": [
    {
      "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "seller": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "sellerName": "Steve",
      "price": 5000,
      "expire_at": 1793161890662,
      "itemInfo": {
        "type": "minecraft:diamond_sword",
        "amount": 1,
        "displayName": "전설의 검",
        "lore": ["강력한 힘이 깃든 검"],
        "enchants": [
          { "id": "minecraft:sharpness", "level": 5 },
          { "id": "minecraft:unbreaking", "level": 3 }
        ]
      }
    }
  ]
}
```

### 상태 확인

#### `GET /health`

API 상태를 확인합니다. 정상이면 `200`, 데이터베이스 연결에 문제가 있거나 목록·Bulk 데이터가 15분 넘게 갱신되지 않았으면 `503`을 반환합니다.  
다른 엔드포인트와 달리 `status`/`data` 형식을 따르지 않습니다.

**Response Fields**

| 필드 | 타입 | 설명 |
|------|------|------|
| `status` | string | `ok` 또는 `unhealthy` |
| `colo` | string | 요청을 처리한 Cloudflare 데이터센터 |
| `version` | string | 배포 버전 |
| `dbMs` | number \| null | 데이터베이스 응답 시간 (ms, 실패 시 `null`) |
| `snapshotAge` | number \| null | 목록·Bulk 데이터가 갱신된 지 지난 시간 (초) |

**Example Request**
```
GET https://api.planetearth.kr/health
```

**Example Response**
```json
{
  "status": "ok",
  "colo": "SEA",
  "version": "6a5df5b8",
  "dbMs": 189,
  "snapshotAge": 66
}
```

## 활용 예시

### 디스코드 인증 봇 (Python)

`!auth` 명령어를 사용한 유저가 `Dev_Island` 마을 소속이면 역할을 지급하고 닉네임을 변경하는 예시입니다.

```python
import discord
import requests

TOKEN = ""    # 봇 토큰
ROLE_ID = ""  # 지급할 역할 ID
TOWN_NAME = "ExampleTown"  # 확인할 마을 이름
HEADERS = {"User-Agent": "AuthBot/1.0 (Minecraft:Steve)"}  # Steve 자리에 본인 닉네임

intents = discord.Intents.default()
intents.message_content = True
intents.members = True
client = discord.Client(intents=intents)

@client.event
async def on_ready():
    print(f"Logged in as {client.user}")

@client.event
async def on_message(message):
    if message.author == client.user:
        return

    if not message.content.startswith("!auth"):
        return

    # 1. 디스코드 ID → 마인크래프트 UUID 조회
    res = requests.get(f"https://api.planetearth.kr/discord?discord={message.author.id}", headers=HEADERS).json()
    if res["status"] != "SUCCESS":
        await message.channel.send("플래닛어스 디스코드에 인증되지 않은 유저입니다.")
        return

    uuid = res["data"][0]["uuid"]

    # 2. UUID → 주민 정보 조회
    res = requests.get(f"https://api.planetearth.kr/resident?uuid={uuid}", headers=HEADERS).json()
    if res["status"] != "SUCCESS":
        await message.channel.send("타우니 데이터를 가져올 수 없습니다.")
        return

    resident = res["data"][0]

    # 3. 마을 확인 후 역할 지급
    if resident["town"] != TOWN_NAME:
        await message.channel.send(f"{TOWN_NAME} 마을에 가입되지 않은 플레이어입니다.")
        return

    guild = message.guild
    role = discord.utils.get(guild.roles, id=int(ROLE_ID))
    await message.author.add_roles(role)
    await message.author.edit(nick=resident["name"])
    await message.channel.send("인증에 성공했습니다! 권한을 지급합니다.")

client.run(TOKEN)
```
