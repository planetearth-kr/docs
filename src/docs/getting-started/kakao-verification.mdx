2026년 9월 15일부터 플래닛어스는 공식 카카오톡 채널을 통한 2차 인증을 진행하고 있습니다. 인증은 카카오톡 챗봇으로 이루어집니다. 인증 정보로는 유저의 카카오톡 ID, 프로필 사진, 프로필 메시지 같은 개인정보를 절대 알아낼 수 없습니다.

## 1. 인증번호 받기

![lobby-verification-code-chat](/img/docs/getting-started/kakao-verification/lobby-verification-code-chat-01.webp)

![lobby-verification-code-action-bar](/img/docs/getting-started/kakao-verification/lobby-verification-code-action-bar-01.webp)

카카오톡 채널 인증을 하지 않은 유저가 로비에 접속하면 채팅과 액션바로 6자리 숫자가 자동으로 발급됩니다.

이 번호는 3분 동안 유효합니다. 3분이 지나면 새로운 여섯 자리 번호가 자동으로 발급됩니다.

## 2. 플래닛어스 공식 카카오톡 채널 접속하기

공식 채널에는 다음 방법으로 접속할 수 있습니다.

- 인게임에서 **\[클릭하여 카카오톡 채널 열기\]** 버튼을 누릅니다.
- 휴대폰으로 오른쪽의 QR코드를 촬영합니다.
- [플래닛어스 카카오톡 채널](http://pf.kakao.com/_xaZBrX/chat) 링크로 접속합니다.

:::tip
위 세 가지 방법으로도 공식 채널을 찾지 못했다면 카카오톡 검색창에 “플래닛어스”를 검색한 뒤 채널 버튼을 누르세요. 공식 채널이 검색됩니다.
:::

![planetearth-kakao-channel](/img/docs/getting-started/kakao-verification/planetearth-kakao-channel-01.webp)

## 3. 인증 진행하기

플래닛어스 공식 카카오톡 채널의 챗봇에게 로비에서 발급받은 여섯 자리 인증번호를 보내면 인증이 완료됩니다.

![kakao-chatbot-verification](/img/docs/getting-started/kakao-verification/kakao-chatbot-verification-01.webp)
