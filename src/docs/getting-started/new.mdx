첫 접속 후 튜토리얼을 마쳤다면 선택지는 크게 두 가지입니다. 기존 유저들이 만든 국가에 가입하거나, 직접 국가를 만드는 것입니다.

## 첫 번째 선택지: 마을(국가)에 가입하기

플래닛어스에서는 **마을(국가)에 소속되어 있어야** 정상적으로 플레이할 수 있습니다.

뉴비 혼자서 마을이나 국가를 설립하고 운영하기는 꽤 어렵습니다. 혼자 오셨다면 다른 마을에 가입하기를 적극 추천합니다. [국가 홍보관](/towny/settlement)이나 마을 가입 신청 기능으로 접속해 있는 유저들에게 가입을 신청하세요.

국가 홍보관과 마을 가입 신청으로 마음에 드는 국가를 찾지 못했다면 디스코드의 [국가 홍보 채널](https://discord.com/channels/971724292482019359/1461627858374885547)을 이용해 보세요.

## 두 번째 선택지: 마을(국가) 직접 만들기

마을에 가입하지 않고 혼자, 또는 지인들과 마을을 만들고 싶다면 [타우니 기초 가이드](/towny/basics)를 확인하세요.

## 앞으로 무엇을 해야 할까요?

- [ ] 마을에 가입하거나 직접 만드세요.
- [ ] `/t spawn` 또는 `/n spawn` 명령어로 소속 마을로 이동하세요.
- [ ] `/nc` 명령어로 채팅 채널을 국가 채팅으로 바꾼 뒤 인사해 보세요.
- [ ] 마을에 초대해 준 사람에게 마을 안내를 받아 보세요.
- [ ] 집을 배정받았다면 `/tsethome` 명령어로 마을 홈을 설정하세요. 이후 마을 스폰에서 `/thome`으로 그 위치까지 순간이동할 수 있습니다.
- [ ] `/지도` 명령어로 지금 있는 지역이 어디인지 확인해 보세요.
- [ ] 아래 설명을 읽고 메인 메뉴의 버튼을 한 번씩 눌러 보세요.

## 뉴비 토큰

플래닛어스는 뉴비와 복귀 유저에게 플레이 타임 한 시간마다 **뉴비 토큰**을 자동으로 지급합니다.

스폰의 뉴비,복귀 토큰 교환원 NPC에서 가진 토큰 개수를 확인하고 토큰을 사용할 수 있습니다. 뉴비 토큰으로 첫 정착에 필요한 아이템을 살 수 있으니, 부족한 것이 있을 때마다 이용하세요.

:::note
뉴비 토큰은 다른 사람에게 양도할 수 없습니다.
:::

![newbie-token-exchange-npc](/img/docs/getting-started/new/newbie-token-exchange-npc-01.webp)

## 경제 활동

플래닛어스에서는 술 제작(양조), 광질, 농사, 무역, 거래, 상점 운영, 요리, 낚시, 특산품 획득 등 여러 방법으로 돈을 벌 수 있습니다.

경제 활동을 시작하기 전에 기본 아이템으로 받은 에메랄드와 밀부터 팔아 보세요.

- [ ] Shift(웅크리기) + F(손 바꾸기)를 눌러 메인 메뉴를 여세요. 서버 상점(MARKET) 버튼을 눌러 상점 메뉴를 연 뒤 에메랄드와 밀을 팔아 보세요. 에메랄드는 광물 상점, 밀은 작물 상점에 있습니다.

![crop-shop-sell-wheat](/img/docs/getting-started/new/crop-shop-sell-wheat-01.webp)

에메랄드와 밀을 팔면 골드를 조금 얻습니다. 가진 골드는 여러 방법으로 확인할 수 있지만, 아래 스코어보드에서 바로 볼 수 있습니다.

### 스코어보드

스코어보드는 자주 봐야 하는 정보를 화면에 항상 보여 주는 기능입니다.

| 항목 | 내용 |
| --- | --- |
| 국가 | 소속된 국가 |
| 마을 | 소속된 마을 |
| 골드 | 가진 골드 |
| 포인트 | 가진 포인트 |
| 병과 | 현재 병과 |
| 채널 | 현재 들어가 있는 채팅 채널 |
| 위치 | 지금 있는 지역의 마을 (야생은 마을이 없는 지역입니다) |
| 나침반 | 현재 위치의 X, Y 좌표 |

![scoreboard](/img/docs/getting-started/new/scoreboard-01.webp)

### 돈 벌어 보기

- [ ] 마을 공용 밭이나 개인 밭을 만들고 작물을 수확해 보세요. 자세한 내용은 [농사](/lifestyle/farming) 문서에서 확인할 수 있습니다.
- [ ] 스폰의 뉴비 광산이나 마을 근처 야생에서 광물을 채집해 보세요.
- [ ] 마을 양조장에서 술을 만들어 보세요. 자세한 내용은 [양조](/lifestyle/brewery) 문서에서 확인할 수 있습니다.
- [ ] 물가에서 물고기를 잡아 팔아 보세요. 자세한 내용은 [낚시](/lifestyle/fishing) 문서에서 확인할 수 있습니다.
- [ ] 스폰의 레스토랑에서 요리를 만들어 팔아 보세요. 자세한 내용은 [요리](/lifestyle/cooking) 문서에서 확인할 수 있습니다.
- [ ] 거래소에서 다른 유저가 파는 아이템을 사 보세요. 메인 메뉴의 AUCTION 버튼을 눌러 이용할 수 있습니다.

이 활동들이 플래닛어스의 가장 기초적인 경제 활동입니다. 무역, 상점 운영, 특산품 획득 등 다른 활동도 있지만 어느 정도 위험이 따르므로 자본을 조금 모은 뒤에 하기를 추천합니다.

## 전투 활동

플래닛어스에는 여러 전투 활동이 있습니다. 국가원들과 힘을 모아 전투 활동에 참여하고 특별한 보상을 얻어 보세요.

전투 콘텐츠에 참여하려면 먼저 아이템을 준비해야 합니다. 체계가 갖춰진 국가는 처음 들어온 뉴비에게 아이템을 보급해 주는 경우가 많습니다. 여기서는 아이템을 직접 준비하는 방법을 안내합니다.

시작하기 전에 [강화](/unique/starforce) 문서와 [병과](/pvp/branch) 문서를 **반드시** 읽으세요.

- [ ] 다이아몬드 갑옷 세트나 뉴비 토큰으로 얻는 뉴비 갑옷 세트, 그리고 자신의 병과에 맞는 주무기를 만들어 보세요.
- [ ] 갑옷 세트와 무기에 인챈트를 해 보세요. 머스킷은 인챈트가 필요하지 않습니다. 갑옷과 무기의 인챈트에는 최대 제한치가 있습니다. 자세한 내용은 [제약사항](/unique/restricted) 문서에서 확인할 수 있습니다.
- [ ] 갑옷 세트를 5강까지 강화해 보세요.
- [ ] 주무기를 10강까지 강화해 보세요.
- [ ] 보조 무기(피스톨, 그래플 등)를 준비해 보세요.
- [ ] 자신의 병과에 맞는 듀얼을 몇 판 해서 주무기 숙련도를 길러 보세요.

아이템을 준비하기가 생각보다 힘들었을 수 있습니다. 다른 사람에게 죽어서 힘들게 준비한 아이템을 모두 잃을까 걱정될 수도 있습니다. 하지만 플래닛어스에서는 특산품 같은 일부 특수 아이템을 제외하면 사망해도 **어떤 아이템도 드랍되지 않습니다**. 다만 인벤토리에 있는 모든 아이템의 내구도가 일정 %씩 감소하므로 내구도를 잘 관리해야 합니다.

아래 활동은 서버를 잘 모르는 상태에서 혼자 가면 아무것도 못 하고 사망할 가능성이 높습니다. 국가원들과 같이 가기를 추천합니다.

- [ ] 특산품을 얻어 보세요. 특산품은 사망하면 드랍되니 주의하세요. 특산품 정보는 `/특산품` 명령어로 확인할 수 있습니다.
- [ ] [컨퀘스트](/pvp/conquest), [점령전(KOTH)](/pvp/koth), [오퍼레이션](/pvp/operation)에 참여해 보세요. 이 콘텐츠들은 보통 매주 일요일 오후 8시 30분에 진행합니다.
- [ ] [전쟁](/pvp/war)에 참여해 보세요. 전쟁은 보통 격주 토요일 오후 8시 30분에 진행합니다.
- [ ] 보석 점령전에 참여해 보세요. 보석 점령전은 보통 매주 금요일과 토요일에 진행합니다. 자세한 내용은 [보석 점령전](/pvp/gem-koth) 문서를 확인하세요.
