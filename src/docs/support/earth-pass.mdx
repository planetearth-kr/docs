플래닛어스에는 시즌제로 운영되는 지구 패스가 있습니다. 지구 패스는 흔히 “배틀 패스”로 알려진 시스템입니다. 주간 퀘스트와 일간 퀘스트를 클리어해 패스 포인트를 모으면 여러 보상을 받을 수 있는 상품입니다.

## UI

### 메인 UI

지구 패스 메인 UI입니다. 메인 메뉴(Shift + F)에서 들어갈 수 있습니다.

![earth-pass-main-ui](/img/docs/support/earth-pass/earth-pass-main-ui-01.webp)

- **Rewards**: 무료 지구 패스와 프리미엄 지구 패스의 보상을 확인하고 받을 수 있는 페이지입니다.
- **Premium**: 자신의 프리미엄 지구 패스 활성 상태와 지구 패스 진행 단계를 확인할 수 있는 버튼입니다.
- **Quests**: 일간·주간 퀘스트를 확인할 수 있는 페이지입니다.
- **Info**: 현재 지구 패스 시즌 정보를 확인할 수 있는 버튼입니다.

### 보상 UI

지구 패스의 무료 보상과 프리미엄 보상을 받을 수 있는 페이지입니다.

![earth-pass-rewards-ui](/img/docs/support/earth-pass/earth-pass-rewards-ui-01.webp)

- **윗줄**: 무료 보상을 받을 수 있는 버튼입니다. 카트에 금화가 있으면 아직 받지 않은 상태입니다.
- **아랫줄**: 프리미엄 보상을 받을 수 있는 버튼입니다. 작동 방식은 윗줄과 같습니다.
- **중간줄**: 지구 패스 진행 단계를 알 수 있는 버튼입니다. 자물쇠가 잠금 해제되었다면 해당 단계에 도달했다는 뜻입니다.

### 퀘스트 UI

지구 패스의 주간 퀘스트와 일간 퀘스트 목록, 진행도를 확인할 수 있는 페이지입니다.

퀘스트는 목표치를 달성하면 자동으로 클리어됩니다.

![earth-pass-quests-ui](/img/docs/support/earth-pass/earth-pass-quests-ui-01.webp)

- **책 아이콘**: N주차 주간 퀘스트의 정보와 진행 상태를 확인할 수 있는 페이지입니다.
- **시계 아이콘**: 일간 퀘스트의 정보와 진행 상태를 확인할 수 있는 페이지입니다.

![earth-pass-weekly-quest-list](/img/docs/support/earth-pass/earth-pass-weekly-quest-list-01.webp)

주간 퀘스트는 지구 패스 시작일부터 1주일마다 새로 추가되며, 보통 4주차 퀘스트까지 있습니다.

![earth-pass-weekly-quest-ui](/img/docs/support/earth-pass/earth-pass-weekly-quest-ui-01.webp)

주간 퀘스트 UI

위 퀘스트 UI에서 책이나 시계 아이콘을 클릭해 퀘스트 정보를 확인할 수 있습니다.

## 유의사항

- 지구 패스 진행 기간이 끝나면 더 이상 퀘스트를 수행할 수 없습니다.
- 스폰에서는 추천 일일 퀘스트를 제외하면 진행도가 오르지 않습니다.

## 지구 패스 시즌 3

지구 패스 시즌 3는 2026년 8월 9일에 출시되어 6주간 진행됩니다.

### 시즌 3 변경점

- 주차별 퀘스트 클리어 포인트 지급 수량 차이가 삭제되었습니다.
- 시즌마다 지급되는 지구 패스 스킨 쿠폰이 추가되었습니다. 과거 배틀패스 토큰과 비슷하며, 쿠폰을 여러 개 모으면 과거 지구 패스 시즌의 치장 아이템으로 교환할 수 있습니다.
- 부담을 줄이기 위해 인게임 플레이에 도움이 되는 아이템은 14티어까지 배치하고, 15티어에는 치장 관련 아이템만 배치했습니다.

### 티어별 요구 패스 포인트

| 8티어, 9티어, 10티어 | 300포인트 |

### 퀘스트 구성

지구 패스 시즌 3에는 메인 퀘스트 4개, 일반 퀘스트 21개, 서브 퀘스트 8개가 있습니다. 이 숫자는 시즌 진행 도중 바뀔 수 있습니다.

### 퀘스트별 지급 포인트

| 퀘스트 | 지급 포인트 |
| --- | --- |
| 메인 퀘스트 | 450포인트 |
| 일반 퀘스트 | 150포인트 |
| 서브 퀘스트 | 75포인트 (100포인트) |

### 지구 패스 클리어 선착순 이벤트

| 순위 | 보상 |
| --- | --- |
| 1등 | 희귀스킨(창, 활, 석궁) 선택 x1, 기간제 칭호 90일, 스폰 표지판, 포인트 1000, 탑햇, 농부 모자 |
| 2등 | 희귀스킨(창, 활, 석궁) 열쇠 x1, 포인트 500, 탑햇, 농부 모자 |
| 3등, 4등 | 포인트 500, 탑햇, 농부 모자 |
| 5등 | 포인트 300, 탑햇 또는 농부 모자 중 택 1 |
| 6, 7, 8등 | 탑햇 또는 농부 모자 중 택 1 |

### 출석체크 지급 포인트

15포인트
