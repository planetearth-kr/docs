마을은 타우니의 기본 공동체입니다. 마을 땅은 외부인으로부터 보호됩니다. 마을은 매일 유지비를 내야 유지됩니다. 단계별 사용법은 [타우니 기초 가이드](/towny/basics)와 [타우니 심화 가이드](/towny/advanced)를 확인하세요.

## 설립과 가입

- `/t new [마을이름]`으로 원하는 곳에 마을을 만듭니다. 마을 설립에는 5000원이 듭니다.
- 서버가 처음인 뉴비에게는 마을 설립보다 다른 마을에 가입하는 것을 추천합니다.
- 마을에 가입한 뒤에는 `/t spawn`으로 마을 스폰으로 이동할 수 있습니다.

플래닛어스에서는 텔레포트가 제한되어 있으므로 마을을 지을 위치를 신중히 정해야 합니다. 위치 선택 기준은 [타우니 기초 가이드](/towny/basics)에 정리되어 있습니다.

## 영토

- `/t claim`으로 서 있는 야생 땅을 마을 땅으로 확장합니다.
- 마을원 1명은 60의 추가 청크를 제공합니다. 단, 180일 이상 접속하지 않은 휴면 유저는 추가 청크를 제공하지 않는 것으로 취급됩니다.
- 시장/부시장은 `/plot fs` 명령어로 마을 청크를 마을원이나 외부인(대사관 플롯)에게 나눠줄 수 있습니다.

플롯 단위로 권한을 나누는 방법은 [타우니 플롯 권한 가이드](/towny/plot-permissions)를 확인하세요.

## 랭크

마을에는 시장 말고도 다음 랭크가 있습니다. 랭크는 `/t rank add/remove [플레이어] 부시장`처럼 명령어 끝에 랭크 이름을 붙여 부여하거나 회수합니다.

| 랭크 | 권한 |
| --- | --- |
| 부시장 | 마을 삭제/합병을 제외하고 시장과 같은 권한 |
| 부관 | 플레이어 초대, 마을 땅 확장 등 제한적인 권한 |
| 사무관 | 인원 초대, 자원 수집, 마을 스폰 설정, 마을 클레임. 추방, 언클레임, 시즈 관련 행동은 불가 |

명령어별 랭크 권한은 [타우니 기초 가이드](/towny/basics)의 마을 권한 목록에서 볼 수 있습니다.

## 마을 권한과 트러스트

마을 권한은 Destroy(블록 파괴 및 동물 킬), Build(블록 설치), Switch(상자 열기), Itemuse(아이템 사용) 4종류입니다. 기본적으로 모든 마을원은 4가지 권한을 모두 가집니다. `/t set perm` 명령어로 마을원, 국가원, 동맹, 외부인별로 권한을 수정할 수 있습니다. 현재 권한은 `/t`로 확인합니다.

트러스트는 일반 마을 권한보다 높은 권한입니다. 트러스트를 받은 플레이어는 마을 땅의 모든 블록과 상자에 대한 권한을 가집니다. 이 권한은 개인 플롯과 마을의 기본 권한보다 우선합니다. 마을 외부인에게도 `/t trust add/remove [외부인 이름]`으로 부여할 수 있습니다.

## 세금과 유지비

- 마을은 `/t set taxes [퍼센트]`로 모든 마을원에게 매일 세금을 걷을 수 있습니다. 세율은 0.875%부터 1.5%까지 설정할 수 있습니다. 한 사람에게 걷을 수 있는 하루 최대 세금은 2000골드입니다.
- 마을원이 세금을 내지 못해도 마을에서 추방당하지 않습니다.
- 모든 마을은 현실 시간 기준 매일 오후 11시에 유지비를 냅니다. 세금도 이때 자동으로 마을원 계좌에서 마을 금고로 빠져나갑니다.
- 마을 유지비는 기본값 500골드에 마을의 영토와 인원수에 비례하여 늘어납니다.

:::caution
유지비를 내지 못하면 마을이 삭제되고, **복구할 수 없습니다**. `/t deposit [금액]`으로 마을 금고에 미리 돈을 넣어두세요.
:::

유지비 계산 방식은 [타우니 유지비 가이드](/towny/upkeep)를 확인하세요.

## 마을 합병

시장은 `/t merge [마을이름]`으로 다른 마을을 합병할 수 있습니다. 상대 마을 시장이 접속 중이어야 합니다. 상대 시장이 수락하면 상대 마을이 합쳐지고 사라집니다. `/pe 마을 합병비용조회 [마을이름]`으로 합병 가능 여부와 비용을 미리 조회할 수 있습니다(시장, 부시장).

- 합병하는 마을의 청크 수가 합병되는 마을보다 많거나 같아야 합니다.
- 합병하는 마을은 100청크 이상, 합병되는 마을은 2청크 이상이어야 합니다.
- 두 마을 스폰 사이의 거리가 300블록 이내여야 합니다.
- 합병되는 마을의 금고 잔액은 합병하는 마을 금고로 옮겨집니다.

나머지 조건과 합병 비용은 [타우니 심화 가이드](/towny/advanced)를 확인하세요.

## 주요 명령어

| 명령어 | 설명 |
| --- | --- |
| `/t new [마을이름]` | 마을 설립 |
| `/t` | 유지비, 보유 금액, 마을 권한 확인 |
| `/t deposit [금액]` | 마을 금고에 입금 |
| `/t invite [플레이어]` | 마을원 초대 |
| `/t claim` | 서 있는 야생 땅을 마을 땅으로 확장 |
| `/t spawn` | 마을 스폰으로 이동 |
| `/t rank add/remove [플레이어] 부시장` | 부시장 랭크 부여·회수 |
| `/t set perm [residence/nation/ally/outsider] [build/destroy/switch/itemuse] [on/off]` | 마을 권한 설정 |
| `/t trust add` | 트러스트 추가 |
| `/t set taxes [퍼센트]` | 세금 설정 |
| `/t merge [마을이름]` | 마을 합병 |
