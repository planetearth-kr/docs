국가는 여러 마을이 모인 공동체입니다. 국가를 만들면 본격적으로 다른 국가와 외교를 할 수 있습니다. 단계별 사용법은 [타우니 기초 가이드](/towny/basics)와 [타우니 심화 가이드](/towny/advanced)를 확인하세요.

## 설립

- `/n new`로 국가를 만듭니다. 국가 설립에는 5000원이 듭니다.
- 마을이 국가에 속해 있으면 `/n spawn`으로 국가 수도로 이동할 수 있습니다.
- `/n deposit [금액]`으로 국고에 돈을 넣습니다.

## 마을 초대

`/n add [마을]`로 마을을 국가에 초대합니다.

새 마을을 초대하려면 해당 마을이 기존 국가 소속 마을과 **25청크 이내**에 있어야 합니다. 비교 대상인 기존 마을도 국가 소속의 나머지 마을과 25청크 이내에 있어야 합니다.

## 외교

- `/n ally`: 국가의 동맹을 관리합니다. 자세한 내용은 [동맹](/towny/alliance)을 확인하세요.
- `/n enemy`: 국가의 적대국을 관리합니다.

## 랭크

국가에는 국왕 말고도 다음 랭크가 있습니다. 랭크는 `/n rank add/remove [플레이어] 부왕`처럼 명령어 끝에 랭크 이름을 붙여 부여하거나 회수합니다.

| 랭크 | 권한 |
| --- | --- |
| 부왕 | 수도 변경, 국가 삭제를 제외한 모든 권한 |
| 부관 | 국가 초대, 동맹 설정, 적대 설정, 스폰 설정 |
| 외교관 | 국가의 동맹, 적대 설정만 가능 |
| 지휘관 | 집결 명령어와 스폰 설정만 가능 |
| 인사부 | 이 역할을 가진 시장/부시장은 뉴비 가입 알림을 먼저 받음 |

인사부는 국가 소속 마을 중 집중적으로 키우고 싶은 마을의 시장에게 부여하는 것을 추천합니다.

## 칭호

국왕 또는 부왕은 국가 채팅과 국가원 목록에 보이는 국가원 이름에 칭호를 붙일 수 있습니다. 칭호에는 마인크래프트 컬러 코드 `&`를 쓸 수 있습니다.

- `/n set title [이름] [접두사]`: 이름 앞에 오는 접두사를 추가합니다.
- `/n set surname [이름] [접미사]`: 이름 뒤에 오는 접미사를 추가합니다.

## 세금과 유지비

- 국가는 `/n set taxes` 명령어로 소속 마을에 세금을 설정할 수 있습니다. 마을과 달리 국가 세금은 퍼센트로 징수할 수 없습니다.
- 모든 국가는 매일 오후 11시에 유지비를 냅니다. 국가 유지비는 국가의 마을 개수, 인원수, 동맹국의 규모에 비례하여 늘어납니다.

:::caution
유지비를 내지 못하면 국가가 삭제되고, **복구할 수 없습니다**.
:::

유지비 계산 방식은 [타우니 유지비 가이드](/towny/upkeep)를 확인하세요.

## 주요 명령어

| 명령어 | 설명 |
| --- | --- |
| `/n new` | 국가 설립 |
| `/n` | 유지비, 보유 금액 확인 |
| `/n deposit [금액]` | 국고에 입금 |
| `/n add [마을]` | 마을 초대 |
| `/n spawn` | 국가 수도로 이동 |
| `/n ally` | 동맹 관리 |
| `/n enemy` | 적대국 관리 |
| `/n rank add/remove [플레이어] 부왕` | 부왕 랭크 부여·회수 |
| `/n set taxes` | 국가 세금 설정 |
| `/n set title [이름] [접두사]` | 국가원 칭호(접두사) 설정 |
