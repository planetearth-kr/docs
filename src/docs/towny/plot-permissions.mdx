## 플롯(Plot)이란

플롯은 마인크래프트의 월드 단위인 청크(16*16칸 안의 모든 블록)와 1대1로 대응되는 타우니의 땅 단위입니다.

![town-size-plot-count](/img/docs/towny/plot-permissions/town-size-plot-count-01.webp)

흔히 "마을 사이즈가 N이다"라고 할 때 N이 마을이 가진 플롯의 수입니다. 위 사진에서는 Town Size가 153이므로, 이 마을은 153개의 플롯(청크)을 자신의 땅으로 가지고 있습니다.

플롯 권한이 어떻게 설정되어 있는지는 `/plot perm hud` 명령어의 UI로 확인할 수 있습니다.

## 플롯 권한 설정이 마을 권한 설정과 다른 점

플롯 권한 설정과 마을 권한 설정의 가장 큰 차이점은 권한을 부여할 수 있는 단위가 다르다는 것입니다.

![plot-permission-hud](/img/docs/towny/plot-permissions/plot-permission-hud-01.webp)

플롯 권한 설정 HUD

![town-permission-hud](/img/docs/towny/plot-permissions/town-permission-hud-01.webp)

마을 권한 설정 HUD

좌측의 플롯 권한 설정은 f, t, a, o 집단에게 권한을 줄 수 있고, 우측의 마을 권한 설정은 r, n, a, o 집단에게 권한을 줄 수 있습니다.

여기서 "집단"이란 그 땅의 주인과 나머지 유저 사이의 "관계"를 뜻합니다. 마을 공용 땅이 아닌 자신의 땅이라면 f는 그 땅 주인의 "친구", t는 그 땅 주인과 "같은 마을원 혹은 같은 국가원"을 뜻합니다. 아래에서 각각의 권한 설정을 자세히 설명합니다.

## 플롯 권한 설정

플롯 권한 설정에는 두 가지 방식이 있습니다.

- 첫 번째는 마을원에게 플롯의 소유권을 주지 않고 시장이나 부시장이 "직접" 관리하는 방식입니다.
시장이나 부시장이 마을 청크 위에 가서 플롯 설정 명령어를 사용합니다.
마을 공용 창고, 국가 공용 창고, 공용 농장 등 공적인 공간에 사용하는 것을 권장합니다.
- 두 번째는 마을원에게 플롯의 소유권을 주고, 플롯 주인이 알아서 관리하게 하는 방식입니다.
마을원에게 해당 플롯의 자치권을 주고, 받은 마을원이 그 플롯 위에서 명령어로 설정합니다. 개인 건축물, 개인 창고 등에 사용하는 것을 권장합니다.

### 플롯 권한 설정 명령어

:::info
`/plot set perm [resident/nation/ally/outsider] [build/destroy/switch/itemuse] [on/off]`<br />
서 있는 플롯의 권한을 설정하는 명령어입니다.
:::

:::info
`/plot trust add [닉네임]`<br />
집단 단위가 아닌 특정 유저에게 플롯 권한을 주는 명령어입니다(마을 트러스트와 비슷합니다).
:::

:::info
`/plot fs [금액]` (기본값 0)<br />
마을원이 설정된 금액을 지불하고 해당 플롯의 소유권을 가져갈 수 있는 상태로 만듭니다.
:::

:::info
`/plot claim`<br />
마을원이 `/plot fs ~`로 취득 가능해진 플롯을 금액을 지불하고 취득합니다.
:::

:::info
`/plot info`<br />
서 있는 플롯의 자세한 정보를 확인합니다.
:::

**사용 예시**

- 내가 서 있는 플롯에서 마을원은 블록 설치만 가능하게 하고 싶다 → `/plot set perm resident off`(해당 플롯에서 마을원의 전체 권한 제거) → `/plot set perm resident build on`(해당 플롯에서 마을원에게 설치 권한 지급)
- 내가 서 있는 플롯에서 국가원은 상자 이용만 가능하게 하고 싶다 → `/plot set perm nation off`(해당 플롯에서 국가원의 전체 권한 제거) → `/plot set perm nation switch on`(해당 플롯에서 국가원에게 Switch 권한을 지급해 상자 이용 가능)
- 특정 플롯에서 집단이 아닌 "특정 유저"에게만 모든 권한을 주고 싶다 → `/plot set perm`
- (시장) 다른 마을원이 플롯을 30골드에 취득하게 하고 싶다
    - `/plot fs 30`
    - `/plot claim`(마을원이 명령어 실행)
    - (마을원) 내가 얻은 플롯에서 나와 친구인 유저에게만 권한을 주고 싶다
        - `/plot set perm off` → `/plot set perm friend on`
- (시장) 누군가 점유 중인 플롯의 점유를 해제하고 싶다 → 해당 청크로 이동한 뒤 `/plot evicit`
- 내가 서 있는 플롯에서 나 말고는 아무도 아무것도 할 수 없게 하고 싶다 → `/plot set perm off`

## 마을 권한 설정

마을 권한 설정은 플롯 권한 설정이 되어 있지 않은 플롯에만 적용됩니다. 소유주가 있거나 따로 설정된 플롯에는 적용되지 않습니다.

### 마을 권한 설정 명령어

:::info
`/t set perm [resident/nation/ally/outsider] [build/destroy/switch/itemuse] [on/off]`<br />
마을 전체 플롯의 권한을 설정하는 명령어입니다.
:::

:::info
`/t trust add [닉네임]`<br />
특정 유저에게 마을의 권한을 모두 줍니다(남용하지 않는 것을 권장합니다).
:::

**사용 예시**

- 우리 마을에서 국가원이 모든 권한을 자유롭게 사용했으면 한다 → `/t set perm nation on`(국가원에게 BUILD, DESTROY, SWITCH, ITEMUSE 권한을 모두 허용)
- 우리 마을에서 국가원이 상자만 열 수 있게 하고 싶다 → `/t set perm nation off`(국가원의 모든 권한 제거) → `/t set perm nation switch on`(국가원에게 SWITCH 권한만 부여)
- 우리 마을에서 동맹원도 상자를 열 수 있게 하고 싶다 → `/t set perm ally off`(동맹의 모든 권한 제거) → `/t set perm ally switch on`(동맹에게 SWITCH 권한만 부여)

## 플롯 그룹 권한 설정 (중요)

앞에서 설명한 플롯 설정에는 단점이 하나 있습니다. 모든 청크마다 따로 설정해야 해서 반복 작업이 많아집니다. 이 문제를 해결하기 위해 타우니에는 플롯 그룹(Plot Group) 기능이 있습니다.

![plot-group-hud](/img/docs/towny/plot-permissions/plot-group-hud-01.webp)

플롯 그룹 기능을 사용하면 `/plot perm hud` 명령어를 사용했을 때 맨 윗줄에 Plot Group 항목이 생깁니다.

## 플롯 그룹 권한 설정 명령어

### 기초

:::info
`/plot group new [그룹명]`<br />
[그룹명]이라는 플롯 그룹을 만들고, 서 있는 플롯을 그 그룹에 포함합니다.
:::

:::info
`/plot group add [그룹명]`<br />
서 있는 플롯이 아무 그룹에도 속해 있지 않다면 [그룹명] 그룹에 소속시킵니다.
:::

:::info
`/plot group remove`<br />
서 있는 플롯을 그룹에서 제거합니다.
:::

:::info
`/plot group delete`<br />
현재 위치한 그룹을 완전히 삭제합니다.
:::

:::info
`/plot group rename [이름]`<br />
현재 위치한 그룹의 이름을 [이름]으로 변경합니다.
:::

### 거래

플롯 그룹도 일반 플롯처럼 마을원 간 거래가 가능합니다.

:::info
`/plot group fs [금액]`<br />
마을원이 [금액]을 지불하고 현재 위치한 그룹을 취득할 수 있게 합니다.
:::

:::info
`/plot group notforsale`<br />
현재 위치한 그룹을 취득할 수 없는 상태로 변경합니다.
:::

### 권한

:::info
`/plot group set perm [friend/town/ally/outsider] [build/destroy/switch/itemuse] [on/off]`<br />
플롯 그룹의 권한을 설정하는 명령어입니다.
:::

**사용 예시**

- 플롯 3개를 Dev라는 그룹에 넣고, 다른 마을원이 이 그룹을 0골드에 취득하게 하고 싶다
    - `/plot group new Dev` → `/plot group add Dev`(나머지 두 청크에서 각각 실행) → `/plot group fs 0`
    - (그룹을 취득한 마을원) 이제 이 그룹은 내 것이다. 이 그룹 안에서 나와 친구인 유저만 자유롭게 활동하게 하고 싶다
        - `/plot group set perm off`(본인 외 모든 유저의 권한 제거) → `/plot group set perm friend on`(본인과 친구인 유저에게만 모든 권한 허용)
- 평소에는 마을원과 국가원이 쓰고, 전쟁 때는 동맹원까지 쓸 수 있는 공용 창고를 만들고 싶다
    - `/plot group new storage` → `/plot group add storage`(처음 new 명령어를 입력한 플롯을 제외하고 원하는 플롯을 모두 넣을 때까지 반복) → `/plot group set perm town switch on`(마을원, 국가원은 상자 사용 가능)
    - (전쟁 시작 전) `/plot group set perm ally switch on`(동맹원에게 이 그룹에 속한 청크의 SWITCH 권한 부여)
    - (전쟁 종료 후) `/plot group set perm ally switch off`(동맹원이 더 이상 이 그룹에 속한 영역의 상자를 사용하지 못함)
