## 요리용 화로

![cooking-furnace](/img/docs/life/cooking/cooking-furnace-01.webp)

요리용 화로는 스폰 주방에서 이용할 수 있습니다.

### 레시피 목록

| 레시피 | 재료 |
| --- | --- |
| 치즈 | 우유 |
| 쌀밥 | 그릇, 쌀 ×2, 물병 |
| 애플파이 | 밀가루, 물병, 사과, 설탕, 버터 |
| 베이크드 포테이토 | 감자, 치즈, 버터 |
| 소고기 토마토 스튜 | 그릇, 생 소고기, 마늘, 토마토, 물병 |
| 알리오 올리오 | 그릇, 파스타, 물병, 고추, 마늘 |
| 샐러드 | 그릇, 토마토, 옥수수, 오이, 양배추 |
| 레어 초밥 | 토막난 물고기 몸통(레어), 쌀밥 |
| 깐풍 가지 | 가지 ×2, 전분 가루, 동물성 기름, 양배추, 마늘, 고춧가루 |
| 피쉬 앤 칩스 | 토막난 물고기 꼬리 ×2, 밀가루, 동물성 기름, 감자 |
| 표고버섯 제육볶음 | 고춧가루, 마늘, 설탕, 돼지고기, 양파, 표고버섯 |

## 방아

방아는 스폰 주방에서 이용할 수 있습니다. 스폰 주방 가장 안쪽에 방아 이용 특화 구역이 있습니다.

![mill](/img/docs/life/cooking/mill-01.webp)

### 레시피 목록

| 레시피 | 재료 |
| --- | --- |
| 밀가루 | 밀 ×2 |
| 파스타 | 밀가루, 물병 |
| 고춧가루 | 고추 ×3 |
| 전분 가루 (감자) | 감자 ×3 |
