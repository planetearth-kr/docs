# 건축용 아이템

## 다이너마이트

![](/img/notion/1ec39199-845f-4523-95b9-ba79eedf2893.webp)

철거 작업을 빠르게 진행할 수 있는 아이템입니다.<br />앉기 상태에서 설치 시 설치된 Y 좌표로부터 같은 청크 내에 있는 블럭들이 위로 64칸까지 파괴됩니다.

- 해당 아이템은 시장 혹은 부시장만 사용 가능하며, 본인의 마을 땅 안에서만 사용할 수 있습니다.
- 청크 내에 상자류 블럭이 있는 경우 사용할 수 없습니다.
- 소형 다이너마이트의 경우 위로 32칸 까지만 파괴됩니다.
- 서버 접속 인원이 270명 이하일 때만 사용 가능합니다.

## 블럭 브러쉬

![](/img/notion/c9243e36-a1aa-4e11-95e1-7e1d175ac30e.webp)

바닥 설치 작업, 제초 작업을 빠르게 진행할 수 있는 아이템입니다.

##### 바닥 설치 작업

앉기 상태에서 목표하는 블럭을 바라보고 좌클릭을 할 경우 해당 블럭이 위치한 청크 내 같은 Y 좌표에 위치한 블럭들이 바라본 블럭으로 변경됩니다.

##### 제초 작업

서있는 상태에서 목표하는 풀(꽃, 잔디, 묘목 등)을 바라보고 좌클릭을 할 경우 해당 청크 내 위치한 풀들이 제초됩니다. (Y 좌표 기준 +-5에만 해당 기능이 적용됩니다)

## 망치

유리를 빠르게 부술 수 있는 아이템입니다.

유리를 바라보고 좌클릭을 할 경우, 유리가 바로 파괴됩니다.<br />일반 망치의 경우 스폰의 아이템 교환 상인을 통해 구매 가능합니다.

![](/img/notion/5dc08739-7e5f-4aaf-8b76-ecc7c0777744.webp)

## 건축가의 작업복

웅크리기(Shift) 상태로 빠르게 움직이게 해주는 바지입니다.

스폰의 상점에서 구매 가능합니다.
