# 요리

![](/img/notion/a7ebbeb8-9268-49cc-ab4f-0571a223a93f.webp)

스폰 바로 왼쪽의 포탈을 통해 스폰 주방으로 이동하여 요리를 진행할 수 있습니다.

## 요리용 화로

![](/img/notion/2c31d292-c8cc-4d93-82c8-e67dd9bdb541.webp)

스폰 주방에서 요리용 화로를 이용할 수 있습니다.

### 레시피 목록

| 레시피 | 재료 |
| --- | --- |
| 치즈 | 우유 |
| 쌀밥 | 그릇, 쌀 ×2, 물병 |
| 애플파이 | 밀가루, 물병, 사과, 설탕, 버터 |
| 베이크드 포테이토 | 감자, 치즈, 버터 |
| 소고기 토마토 스튜 | 그릇, 생 소고기, 마늘, 토마토, 물병 |
| 알리오 올리오 | 그릇, 파스타, 물병, 고추, 마늘 |
| 샐러드 | 그릇, 토마토, 옥수수, 오이, 양배추 |
| 레어 초밥 | 토막난 물고기 몸통(레어), 쌀밥 |
| 깐풍 가지 | 가지 ×2, 전분 가루, 동물성 기름, 양배추, 마늘, 고춧가루 |
| 피쉬 앤 칩스 | 토막난 물고기 꼬리 ×2, 밀가루, 동물성 기름, 감자 |
| 표고버섯 제육볶음 | 고춧가루, 마늘, 설탕, 돼지고기, 양파, 표고버섯 |
