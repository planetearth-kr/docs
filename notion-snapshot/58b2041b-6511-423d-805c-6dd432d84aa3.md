| **채팅 명령어** |  |
| 채팅 맨 앞에 ! ex) !안녕하세요 | 전체채팅 |
| /l | 지역채팅 |
| /tc | 마을채팅 |
| /nc | 국가채팅 |
| /ac | 동맹채팅 |
|  |  |
| **주민 명령어** |  |
| /res 또는 /res \<플레이어\> | 플레이어 정보 확인 |
|  |  |
| **마을 명령어** |  |
| /t help 또는 /t ? | 모든 마을 명령어를 확인합니다 |
| /t 또는 /t \<마을이름\> | 마을 정보를 확인합니다. |
| /t new \<마을이름\> | 새 마을을 설립합니다. 5000원의 돈이 지불됩니다. |
| /t list<br />/t list by \<정렬방식\> | 서버에 존재하는 마을들을 나열합니다<br />\<정렬방식\>으로 마을들을 나열합니다. |
| /t spawn | 마을 스폰으로 이동합니다. |
| /t deposit \<금액\> | 마을 은행으로 \<금액\>만큼 입금합니다. |
| /t online | 접속중인 마을원들을 확인합니다. |
| /t leave | 소속된 마을을 떠납니다. |
|  |  |
| **국가 명령어** |  |
| /n 또는 /n \<국가이름\> | 국가 정보를 확인합니다. |
| /n help 또는 /n ? | 모든 국가 명령어를 확인합니다. |
| /n new \<국가이름\> | 새 국가를 설립합니다. 5000원의 돈이 마을 금고에서 지불됩니다. |
| /n list<br />/n list by \<정렬방식\> | 서버에 존재하는 국가들을 나열합니다<br />\<정렬방식\>으로 국가들을 나열합니다. |
| /n list by online | 접속중인 국민 수가 많은 순으로 국가를 나열합니다. |
| /n spawn | 국가 스폰으로 이동합니다. |
| /n deposit \<금액\> | 국가 은행으로 \<금액\>만큼 입금합니다. |
| /n online | 접속중인 국가원들을 확인합니다. |
|  |  |
| **시장 명령어** |  |
| /t mayor | 모든 마을 시장 명령어를 확인합니다. |
| /t add \<플레이어\> 또는 /t invite \<플레이어\> | 플레이어를 마을에 초대합니다. |
| /t kick \<플레이어\> | 플레이어를 마을에서 추방합니다. |
| /res set mode townclaim, /자동클레임 | 플레이어를 자동 클레임 모드로 설정합니다. |
| /res set mode clear, /자동클레임해제 | 플레이어의 모드를 기본 상태로 되돌립니다. |
| /t set spawn | 현재 서있는 위치를 마을 스폰으로 지정합니다. |
| /t set homeblock | 현재 서있는 위치를 마을 홈블럭으로 지정합니다.<br />마을 스폰을 지정하기 전에 사용해야 합니다. |
| /t claim | 현재 서있는 야생 땅을 점유합니다.<br />20원부터 시작하여 소유한 마을 청크의 개수에 비례하여 가격이 올라갑니다. |
| /t unclaim  | 현재 서있는 마을 땅을 점유 해제합니다. <br />점유 해제 시 야생 땅으로 돌아갑니다. |
| /t withdraw \<금액\> | 마을 은행에서 \<금액\>만큼의 돈을 출금합니다. |
| /t rank add \<플레이어\> \<랭크\> | 플레이어에게 \<랭크\>권한을 부여합니다.<br />사용 가능 랭크: 부시장, 부관, 사무관 |
| /t rank remove \<플레이어\> \<랭크\> | 플레이어에게 \<랭크\> 권한을 박탈합니다. |
| /t trust add \<플레이어\> | \<플레이어\>에게 TRUST 권한을 부여합니다.<br />TRUST 권한이 있는 유저는 마을 소속이 아니더라도 마을의 블럭 설치/파괴 및 상자 열기 권한을 가집니다.<br />TRUST 권한은 개인 플롯 권한보다 우선시되는 가장 높은 권한입니다. |
| /t trust remove \<플레이어\> | \<플레이어\>의 TRUST권한을 박탈합니다. |
| /t outlaw add \<플레이어\> | \<플레이어\>를 마을 무법자로 설정합니다.<br />무법자가 마을 땅 안에 들어올 시 자동으로 외부로 TP됩니다.<br />원치 않는 외부인이 마을 땅 안에서 머무를 때 사용하세요.<br />전쟁 시간 동안 또는 전투 상태일때는 발동되지 않습니다.<br />같은 마을원을 무법자로 설정하면 자동으로 마을에서 추방됩니다. |
| /t outlaw remove \<플레이어\> | \<플레이어\>를 마을 무법자에서 삭제합니다. |
| /t outlawlist | 마을의 모든 무법자 목록을 확인합니다. |
| /t set | SET 구문과 관련된 명령어들을 나열합니다. |
| /t toggle | TOGGLE 구문과 관련된 명령어들을 나열합니다. |
| /t merge \<마을이름\> | \<마을이름\> 마을에게 자신의 마을과 합병할 것을 요청합니다. 수락 시 \<마을이름\> 마을은 해체됩니다.<br />명령어를 입력하는 플레이어가 시장, 부시장 랭크를 둘 다 가지고 있으면 합병할 수 없습니다. |

|  |  |
| **국가 왕 명령어** |  |
| /n king | 국가 왕의 모든 명령어를 확인합니다. |
| /n add \<마을이름\> | \<마을이름\>의 마을을 국가로 초대합니다. 수락시 마을이 국가로 편입됩니다. |
| /n remove \<마을이름\> | \<마을이름\>의 마을을 국가에서 추방합니다. |
| /n set spawn | 현재 서있는 위치를 국가 스폰으로 지정합니다.<br />국가 스폰은 국가 영토 내 마을 상관없이 어디든지 지정 가능하지만, 현재 스폰에서 최대 1천블럭만 움직일 수 있습니다. |
| /n set | SET 구문과 관련된 명령어들을 나열합니다. |
| /n ally | 국가 동맹 설정을 엽니다 |
| /n enemy add \<국가이름\> | \<국가이름\>을 적대합니다. \<국가이름\>의 국가원들의 네임태그가 빨간색으로 표시되며, 적대국 국민들은 국가의 영토에 들어올 수 없습니다. |
| /n enemy remove \<국가이름\> | \<국가이름\>의 국가의 더이상 적대하지 않습니다. |
| /n merge \<국가이름\> | \<국가이름\> 국가에게 자신의 국가와 합병할 것을 요청합니다. 수락 시 \<국가이름\> 국가는 해체됩니다.  새 수도와 거리가 1만블럭 이상인 마을들은 국가에서 자동으로 추방당합니다.<br />명령어를 입력하는 플레이어가 왕, 부왕 랭크를 둘 다 가지고 있으면 합병할 수 없습니다.  |
| /n rank add \<플레이어\> \<랭크\> | 플레이어에게 \<랭크\>권한을 부여합니다.<br />사용 가능 랭크: 부왕, 부관, 외교관, 지휘관 |

| **플롯 명령어** |  |
| /plot fs \<가격\> | 서있는 마을 청크를 \<가격\>에 판매합니다. |
| /plot claim | 마을원이 판매중인 청크의 위에서 입력시 서있는 청크를 가격을 지불하고 구매합니다. |
| /plot perm | 서있는 마을 청크의 권한을 확인합니다. |
| /plot perm hud | 서있는 땅의 권한 정보를 스코어보드에 표시합니다. |
| /plot set perm | 서있는 마을의 청크의 권한을 설정합니다. |
| /plot clear | 서있는 마을 청크의 모든 표지판을 제거합니다.<br />잠겨 있는 상자나 문 또한 언락됩니다. |

| **특수 명령어** |  |
| /타우니초기화 | 마을, 국가의 외교 관계와 트러스트, 잠수유저를 관리합니다. |
| /시장승계 | • 마을 시장이 장기 부재할 경우, 다른 마을원들은 `/시장승계` 명령어로 시장을 승계받을 수 있습니다.<br />• 마을 시장의 미접속 25일차부터 부시장이 시장직 승계가 가능합니다. 30일차부터는 일반 마을원도 승계받을 수 있습니다.<br />• 마을에 승계받을 부시장이 없는 경우에는 일반 마을원도 25일차부터 승계받을 수 있습니다. <br /><br />서버측에서는 마을의 시장을 임의로 교체해드리지 않습니다. |
| /tsethome | 개인 마을 홈을 지정합니다 |

| /국가스폰위치 | 국가 스폰 위치를 확인합니다 |
| /마을방송 | 마을원 전체에게 공지문을 보냅니다 |
