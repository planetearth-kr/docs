# 플래닛어스 전용 명령어 가이드

\<?\> - 옵션, \[ ? \] - 필수

## 메인서버 전용

![](/img/notion/0db4c798-3582-4b3c-8e3c-c6c1dab7d724.webp)

## 기본 명령어

/낚시대회 - 진행중인 낚시대회의 순위를 봅니다.

/출석체크, /출첵 - 출석체크 메뉴를 엽니다.

/전과 \<숫자\> - 자신의 전과 기록을 확인합니다.

/goods \<이름\> - 전체 특산품 혹은 \<이름\>을 포함하는 특산품의 리스폰 상태를 검색합니다.

/woods - 나무 특산품들의 리스폰 시간을 검색합니다.

/sand - 모래 특산품들의 리스폰 시간을 검색합니다.

/tl - 자기 자신의 좌표를 참여중인 채팅 채널에 전송합니다.

/pe toggle \<선택\> - 서버의 여러 기능을 켜고 끕니다.

/병과 - 병과를 변경합니다. 자세한 내용은 전투 가이드의 병과 페이지를 참고하세요.

/원격교환 \[상점 타입\] - Basic 이상 혜택으로, 스폰에 있는 교환 NPC들을 원격으로 사용합니다.

/sb - 스코어보드 on,off

/pe 토큰생성 - 에메랄드를 들고 명령어를 사용하면 자신만의 전용 토큰 아이템이 생깁니다.

## 타우니 관련

/자동클레임 - 서있는 청크를 자동으로 점유합니다.<br />/자동클레임해제 - 위 명령어를 취소합니다.

/자동언클레임 - 서있는 청크를 자동으로 포기합니다.<br />/자동언클레임해제 - 위 명령어를 취소합니다.

/lft - 가입할 마을을 찾는 메시지를 자동으로 보내줍니다.

/lfr - 주민을 모집한다는 메시지를 자동으로 보내줍니다.

/타우니초기화 \<옵션\> - 무법자, 트러스트, 동맹국, 적대국을 초기화합니다.

/국가공지 \[공지 메시지\] - 국가원이 들어올 때 나오는 타이틀 메시지를 설정합니다.

/국가방송 \[공지 메시지\] - 150골드를 소모하여 실시간으로 국가원들에게 타이틀 메시지를 보여줍니다.

/시장승계 - 마을 시장이 특정 기간 이상 잠수일 경우 같은 마을원이 해당 명령어로 시장을 획득할 수 있습니다.<br />/online - 접속중인 국가/동맹국의 인원을 봅니다.

/국가스폰위치 - 자기 국가의 스폰 위치를 봅니다.

/tsethome - 마을 홈을 설정합니다. 자기 마을 안에서만 사용 가능합니다.

/thome - 마을 홈으로 이동합니다. 자기 마을 스폰 근처 16블럭에서만 마을 홈으로 이동할 수 있습니다.

/psethome, /phome - tsethome과 같은 역할로, 베이직 랭크 이상부터 사용 가능합니다.(베이직 랭크는 사용 시 10골드가 소모됩니다.)

/집결 - 근처 아군에게 어디로 모이라고 알람을 보냅니다. 특정 계급 이상만 사용 가능합니다. `/집결` 뒤에 아무 문구나 붙이면, 같은 국가원에게만 해당 알람이 전송됩니다.
